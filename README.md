# README

This is a lightweight rails app designed to test cross domain tracking between GOV.UK and other government sites. 

It relies on a branch of [govuk-publishing-components](https://github.com/alphagov/govuk_publishing_components/pull/5511) to do this.

This is only meant to be a single page running the code from the linked branch of publishing components so doesn't really hold much logic.

At some point it'll be deployed to GCP to also test the GTM side of cross domain tracking
